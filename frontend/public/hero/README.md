# Hero media

Drop a file named `hero.mp4` in this folder and the home page hero will play it
in the right-hand panel automatically — no code change needed.

- Portrait (9:16) or square works best; the panel is tall on desktop.
- Keep it under ~8 MB. It autoplays muted and loops, so it must be short.
- Add `hero-poster.jpg` alongside it for the first frame shown while it loads.

Without `hero.mp4` present the panel falls back to a typeset bottle card.
